**LARGE LANGUAGE MODEL(LLM):**

A Large Language model is a artificial intellegence model in which it helps to understand,generate and manipulate human language
It is a interaction between an user and a AI Assistant 
          USER--------------   LLM----------- AI ASSISTANT
It only deals with the text
LLM is trained using Deep Learning by giving a Large Set of Data. The Data is been trained by books ,public data ,websites, research papers etc

**TYPES OF LLM MODELS:**

GPT MODELS: Developed by OpenAI
      GPT1 --- GPT2 ---- GPT3 ---ChatGPT ---GPT4
GOOGLE BERT: Developed by Google
LLAMA: Developed by Meta

**CHARACTERSTICS OF LLM:**
Large Scale: Using Parameters the model is predicted.Parameters are the internel variable used to adjust and learn during training
Large Amount of Diverse Data
Tranformer Architecture: It helps to recongnize longer text  and handles the words using self attention

**NEXT TOKEN PREDICTION**

-Given Context,Predict Proboblity of next character
-Classification problem over 27 classes
-Foundation of every Large Language Model

**HOW LLM ACTUALLY WORKS**

           PROMPT----TOKENS---EMBEDDINGS----ATTENTION----TRANFORMERS---NEW TOKENS----ANSWER
           (USER)                                                                    (OUTPUT)

  -PROMPT-The Text provided by the user
  -TOKENS-Breaks the text/words into smaller numbers
  -EMBEDDINGS-These numbers will then form long list .from this sequence of list it is trained
  -ATTENTION-Instead of treating every word equally the model works out which works out
  -TRANSFORMER -H-ot layer in whichtravels through so many layers
